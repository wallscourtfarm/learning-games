🎲 Spelling Games — Pupil Cards

Print, cut out and hand one card to each child. They scan a game's QR code (or open that game and type their code) then enter their PIN.

Proof of concept — QR codes are generated in your browser using the qrcode-generator library (MIT licence, vendored locally in vendor/qrcode.js, no external service or network call). PINs live in roster.js alongside this page, shared by every game — treat that file the way you'd treat a class list, not a secrets store. Each pupil's year and the shared CURRENT_WEEK (both in roster.js) are baked into every QR code, so scanning one opens that game already loaded with the right week's words — no picker needed. Add a new game to every pupil's card by adding one entry to the GAMES list in roster.js — nothing else on this page needs to change.
