🎲 Spelling Games — Pupil Cards

Print, cut out and hand one card to each child. They scan their code (or open their page and type it) to see everything they can play this week.

Proof of concept — QR codes are generated in your browser using the qrcode-generator library (MIT licence, vendored locally in vendor/qrcode.js, no external service or network call). Pupils and the current week come live from the "Roster" and "Settings" tabs in the backend Google Sheet — type a name in the Sheet and a code + PIN fill themselves in, no code or GitHub needed. roster.js is only the offline fallback used if that Sheet is unreachable. Each card's QR code goes to play/index.html — a pupil's own page listing every game available for their year and the current week — rather than one QR per game, so a new game never means reprinting cards. Add a new game to that list by adding one entry to GAMES in roster.js.
